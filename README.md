# PDF Presenter Pacemaker

PDFスライドを使った発表向けに、時間進捗、スライド進捗、ページごとのトークメモを同時に確認できるローカルWebアプリです。

## 起動手順

Node.js 24以上を使用してください。

```bash
npm install
npm run dev
```

ブラウザで表示されたローカルURLを開きます。

本番ビルド確認:

```bash
npm run build
npm run preview
```

## 使用方法

1. PDFファイルを選択します。
2. 発表時間を分単位で入力します。
3. 必要に応じてトークメモMarkdownを入力します。
4. `開始` を押すと発表画面に移動し、タイマーが開始します。
5. `前へ` / `次へ` またはキーボードでページを移動します。
6. 🐇 は時間進捗、🐢 はスライド進捗を表します。

## キーボード操作

- `ArrowRight`, `Space`: 次ページ
- `ArrowLeft`: 前ページ
- `Home`: 先頭ページ
- `End`: 最終ページ
- `f`: フルスクリーン切り替え
- `p`: タイマーの一時停止 / 再開
- `r`: タイマーリセット

入力欄にフォーカスがある場合、ショートカットは無効になります。

## 主要コンポーネント

- `PdfLoader`: PDF、発表時間、トークメモの入力画面
- `PdfCanvas`: PDF.jsを使った現在ページのcanvas描画
- `PresenterLayout`: 発表画面全体のレイアウト
- `TimerControls`: 開始、一時停止、リセット、フルスクリーン操作
- `ProgressRace`: 🐇 と 🐢 による時間/スライド進捗表示
- `TalkNotePanel`: 現在ページのトークメモ表示

## トークメモMarkdownの書き方

ページ番号を `# 数字` で書き、その次の見出しまでを該当ページのメモとして扱います。

```md
# 1

今日はPDF発表ビューアについて話します。

# 2

通常のPDFビューアでは、時間配分が見えにくいです。
```

メモがないページでは `メモなし` と表示されます。
