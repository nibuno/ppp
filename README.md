# PDF Presenter Pacemaker

PDFスライドを使う発表者のためのデスクトップアプリです。発表者画面では、現在のスライド、残り時間、ページごとのトークメモ、時間とスライドの進み具合をまとめて確認できます。投影用の別ウインドウにはスライドだけを表示します。

## 主な機能

- PDFの読み込み（最大200MB）
- 発表時間とページ別トークメモの設定
- 発表者画面と投影画面の分離
- ページ移動、タイマー操作、フルスクリーン表示
- 発表者画面と投影画面のページ・タイマー同期
- 🐇（時間）と🐢（スライド）による進捗表示

## 開発環境

- Node.js 24以上
- npm 10以上
- Rust stable
- Tauri 2のビルドに必要なOS別ツールチェーン

依存関係をインストールし、Tauriの開発モードで起動します。

```bash
npm install
npm run tauri:dev
```

`npm run dev` はTauriが内部で利用するフロントエンド開発サーバーだけを起動するコマンドです。アプリ単体の動作確認には `npm run tauri:dev` を使用してください。

## 使い方

1. PDFファイルを選択またはドロップします。
2. 発表時間を分単位で入力します。
3. 必要に応じてページ別のトークメモを入力します。
4. `発表を開始` を押します。
5. 必要に応じて `投影画面を開く` を押し、別ウインドウをプロジェクター側へ移動します。
6. ページ操作とタイマー操作は発表者画面で行います。

## キーボード操作

- `ArrowRight`, `Space`: 次のページ
- `ArrowLeft`: 前のページ
- `Home`: 最初のページ
- `End`: 最後のページ
- `f`: フルスクリーン切り替え
- `p`: タイマーの一時停止・再開
- `r`: タイマーのリセット

入力欄にフォーカスがある間、これらのショートカットは無効です。

## トークメモ

ページ番号を `# 数字` の見出しとして書き、次のページ見出しまでをそのページのメモとして扱います。

```md
# 1

最初のページで話す内容。

# 2

次のページで話す内容。
```

## 検証とビルド

```bash
npm run lint
npm test
npm run build
npm run rust:fmt
npm run rust:clippy
npm run rust:test
```

配布用デスクトップアプリを生成する場合は次を実行します。

```bash
npm run tauri:build
```

成果物は `src-tauri/target/release/bundle/` 以下に生成されます。

## 構成

- `src/`: Reactによる画面、PDF描画、Tauriコマンドの呼び出し
- `src-tauri/`: ウインドウ管理、PDFデータ、ページ、タイマーの共有状態
- `SPEC.md`: 現在の実装に対応する技術仕様

## 現在の制約

- 対応するスライド形式はPDFのみです。
- 発表データやリハーサル履歴は永続化されません。
- 投影画面の操作は発表者画面から行います。
